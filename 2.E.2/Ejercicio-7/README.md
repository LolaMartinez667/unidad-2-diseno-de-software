# 2.E.2 - Ejercicio 7: Numeros de atencion

## Objetivo

Emitir numeros consecutivos desde varias terminales, conservando el ultimo numero y el historial de entregas.

## Implementacion

`Ejercicio07NumerosAtencion` centraliza el contador y sincroniza la emision para que no se repitan numeros.

## Compilar y ejecutar

```powershell
javac -d out src\Ejercicio07NumerosAtencion.java
java -cp out unidad2.e2.Ejercicio07NumerosAtencion
```
