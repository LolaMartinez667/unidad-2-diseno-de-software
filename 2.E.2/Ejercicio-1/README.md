# 2.E.2 - Ejercicio 1: Configuracion de biblioteca

## Objetivo

Compartir el nombre de la biblioteca, el limite de libros y el plazo de devolucion entre los sectores de prestamos y consultas.

## Implementacion

`Ejercicio01ConfiguracionBiblioteca` valida los valores y los modulos de demostracion comprueban que reciben la misma instancia.

## Compilar y ejecutar

```powershell
javac -d out src\Ejercicio01ConfiguracionBiblioteca.java
java -cp out unidad2.e2.Ejercicio01ConfiguracionBiblioteca
```
