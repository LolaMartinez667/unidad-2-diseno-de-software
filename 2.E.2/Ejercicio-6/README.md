# 2.E.2 - Ejercicio 6: Configuracion de hospital

## Objetivo

Compartir nombre, horario de atencion y duracion de turnos entre recepcion y consultorios.

## Implementacion

`Ejercicio06ConfiguracionHospital` usa inicializacion diferida y valida que el cierre sea posterior a la apertura y que la duracion sea positiva.

## Compilar y ejecutar

```powershell
javac -d out src\Ejercicio06ConfiguracionHospital.java
java -cp out unidad2.e2.Ejercicio06ConfiguracionHospital
```
