# 2.E.2 - Ejercicio 4: Administrador de prestamos

## Objetivo

Evitar que dos mostradores presten el mismo ejemplar y permitir registrar devoluciones y consultar prestamos activos.

## Implementacion

`Ejercicio04AdministradorPrestamos` administra los ejemplares prestados en una unica instancia. El ejemplo muestra el rechazo de un segundo prestamo del mismo ejemplar.

## Compilar y ejecutar

```powershell
javac -d out src\Ejercicio04AdministradorPrestamos.java
java -cp out unidad2.e2.Ejercicio04AdministradorPrestamos
```
